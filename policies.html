Homework

Submission deadlines

Take home assignments are to be submitted before 5pm on Thursday via student’s individual websites or Courseworks. See specific assignment for directions. The TA and instructor will start reviewing submissions at that time.

Commenting code

Commenting your code and attributing code you use are required as part of every programming assignment and ensures that you receive credit for assignments. Writing comments inline with the code also helps you to think through how to best complete particular programming tasks and also helps the instructor troubleshoot with you.

Plagiarism

Plagiarism can be a serious issue in programming courses. In the context of this course, it is permissible to use pieces of code you find in the wild that suits your project under these circumstances:

  • You have checked the author’s permissions and their work is under either a creative commons, MIT, or similar license in which noncommercial use is permitted.
  • That you include clear attributions of the code you incorporate from others as comments directly within your work. This includes, to the extent available, the author’s name, the URL of the work, and a sentence explaining the function of the code.

Artificial intelligence use

It is permissible to use AI assisted code generators to simplify the writing of syntax in this course only under these circumstances:

  • The student fully understands the purpose of the code generated, and is able to answer questions about the general function of portions of the code.
  • That the student is fully and solely responsible for the output of the code generated, especially including how data is treated.
  • The student documents in detail the prompt used to generate specific outputs, and attributes the AI that is used as a source.
